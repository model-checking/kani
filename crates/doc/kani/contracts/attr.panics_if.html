Attribute Macro panics_if 

#[panics_if]
Expand description

State a condition under which this function must panic.

This is part of the function contract API, for more general information see the module-level documentation.

The contents of the attribute is a condition over the input values to the annotated function, with the same restrictions as a requires condition. It is evaluated on entry, after the preconditions.

A proof_for_contract harness checks that the function does not return when the condition held on entry. Without a panics_only_if clause, the function may also panic only if the condition held, so panics_if(cond) states that the function panics if and only if cond holds. With a panics_only_if(c) clause, the function may panic only if c held, so cond must imply c: the inputs where c holds but cond does not are those where the function may or may not panic.

When the function is replaced by its contract (stub_verified), the replacement panics whenever the condition holds.

A function may have at most one panics_if clause.
