Attribute Macro panics_only_if 

#[panics_only_if]
Expand description

State the only condition under which this function may panic.

This is part of the function contract API, for more general information see the module-level documentation.

The contents of the attribute is a condition over the input values to the annotated function, with the same restrictions as a requires condition. It is evaluated on entry, after the preconditions.

A proof_for_contract harness checks that the function panics only if the condition held on entry: a panic when it did not hold is a verification failure. Undefined behavior is still checked on every path, including paths that panic, and postconditions are checked whenever the function returns. The condition is necessary for a panic, not sufficient: to require that the function panics, use panics_if.

When the function is replaced by its contract (stub_verified), the replacement may panic whenever the condition holds, so callers have to account for that panic.

A function may have at most one panics_only_if clause.
